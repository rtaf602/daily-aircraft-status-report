# สภาพ บ.ประจำวัน ฝูง.602

หน้าเว็บสำหรับกรอกแบบฟอร์ม "สภาพ บ.ประจำวัน" แล้วออกเป็น PDF ขนาด A4 และไฟล์ Excel

โค้ดของหน้าเว็บอยู่ใน `src/page.html` คำสั่ง `node build.mjs` ประกอบเป็นหน้าเว็บสองรูปแบบ:

| ไฟล์ที่ได้ | ใช้ที่ไหน | บันทึกข้อมูล |
|---|---|---|
| `dist/daily-aircraft-status.html` | เผยแพร่เป็น artifact บน Claude | เก็บร่วมกันทุกเครื่อง และส่งเข้า Google Sheet ผ่าน Claude |
| `site/index.html` | เว็บทั่วไป เช่น GitHub Pages | เก็บร่วมกันทุกเครื่อง และส่งเข้า Google Sheet ผ่าน **ระบบหลังบ้านบน Google Apps Script** (`backend/`) |

ถ้ายังไม่ได้ใส่ที่อยู่ระบบหลังบ้านใน `build.config.json` เว็บรุ่น `site/` จะเก็บข้อมูลในเบราว์เซอร์ของแต่ละเครื่อง และไม่ส่งเข้า Google Sheet

**ขั้นตอนติดตั้งระบบหลังบ้านและเปิดเว็บ อยู่ใน [`backend/SETUP_TH.md`](backend/SETUP_TH.md)**

## ข้อควรรู้ก่อนเปิดเป็นเว็บบน GitHub Pages

1. **เว็บบน GitHub Pages เป็นสาธารณะ** ทุกคนที่มีลิงก์เปิดหน้าเว็บได้ และบัญชี GitHub แบบฟรีเปิด Pages ได้เฉพาะ repo ที่เป็น Public
   เมื่อต่อกับระบบหลังบ้าน ผู้เปิดต้องพิมพ์ **รหัสเข้าใช้งาน** ก่อน จึงจะเห็นหรือบันทึกข้อมูลได้ รหัสนี้ตรวจที่ระบบหลังบ้าน ไม่อยู่ในหน้าเว็บและไม่อยู่ใน repo นี้
2. ไฟล์ใน repo นี้ไม่มีรหัสผ่าน ลิงก์ Google Sheet ชื่อหรือเบอร์โทรผู้ดูแล และไม่มีข้อมูลรายงาน
   สิ่งที่มีและจะเป็นสาธารณะไปด้วย คือรายการเครื่องบินตั้งต้นในโค้ด และค่าแฮชของรหัสผ่านของหน้าเว็บ (รหัสสั้นเดาย้อนกลับได้ง่าย จึงไม่ใช่ด่านกันคนนอก)
3. ระบบหลังบ้านทดสอบกับตัวจำลองของ Google แล้ว แต่ยังไม่เคยรันบน Google จริง ให้ทดลองตามคู่มือก่อนใช้งานจริง
4. ใช้งานที่เดียว: เมื่อย้ายมาเว็บนี้แล้ว ให้เลิก SAVE บนหน้า Claude

## นำขึ้น GitHub

**แนะนำให้สร้าง repo แบบ Private**

วิธีที่ 1 — ผ่านหน้าเว็บ GitHub
1. เข้า github.com กด New repository ตั้งชื่อ เลือก **Private** แล้วกด Create repository
2. ในหน้า repo กด "uploading an existing file" (หรือ Add file → Upload files)
3. ลากไฟล์และโฟลเดอร์ **ทั้งหมดที่อยู่ข้างในโฟลเดอร์ `aircraft-status-602`** ไปวาง แล้วกด Commit changes
   ตรวจว่ามีโฟลเดอร์ `.github` และไฟล์ `.gitignore` ติดไปด้วย (บน Mac ต้องกด Command + Shift + . ใน Finder เพื่อให้เห็นไฟล์ที่ขึ้นต้นด้วยจุด)
4. **ห้ามอัปโหลดโฟลเดอร์ `aircraft-status-602-private`**

วิธีที่ 2 — ให้ Claude Code ทำ
เปิด Claude Code ในโฟลเดอร์ `aircraft-status-602` แล้วสั่ง เช่น "สร้าง repo แบบ private บน GitHub ชื่อ aircraft-status-602 แล้ว push โฟลเดอร์นี้ขึ้นไป"

## เปิดเป็นเว็บบน GitHub Pages

ทำตาม [`backend/SETUP_TH.md`](backend/SETUP_TH.md) ตั้งแต่ต้น ตัวเผยแพร่ไม่ทำงานเอง ต้องกด Run workflow ทุกครั้งที่ต้องการเผยแพร่รุ่นใหม่

## สำหรับผู้พัฒนา

ต้องมี Node 18 ขึ้นไป

    node build.mjs      # ประกอบหน้า (ไม่ต้องติดตั้งอะไรเพิ่ม)
    npm install && npx playwright install chromium
    npm test            # ชุดทดสอบ ต้องมีโฟลเดอร์ private ที่ไม่ได้อยู่ใน repo นี้

รายละเอียดทั้งหมดอยู่ใน `CLAUDE.md`
